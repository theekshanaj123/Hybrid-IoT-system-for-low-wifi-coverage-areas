# Hybrid IoT System for Low Wi-Fi Coverage Areas

This project builds a hybrid IoT network that uses a **central Wi-Fi hub** and multiple **NRF24-based wireless nodes**.  
It is designed to work in places where Wi-Fi coverage is weak. The NRF24 nodes communicate with the hub using RF signals, and the hub sends data online using Wi-Fi.

---

##  Features
- Works in low or weak Wi-Fi coverage areas  
- Long-range NRF24 wireless communication  
- Only the hub requires Wi-Fi  
- Low power node operation  
- Easy to expand with more nodes  
- Supports multiple sensors
